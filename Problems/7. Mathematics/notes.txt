---------- Вектори

Ако имаме т. M(2, 3, 4) и т. N(6, 7, 8), тогава векторът MN е с координати (4, 4, 4) и дължината му е:
    |MN| = √(4² + 4² + 4²) = 4√3

Векторното произведение на AB(1, -2) и AC(-4, 0) в равнината се пресмята:

                | 1 -2 |
    |AB x AC| = | -4 0 | = 1 * 0 - ((-2) * (-4)) = -8

Векторното произведение на AB(1, -2, 2) и AC(-4, 0, -3) в пространството се пресмята:

                 | -2 2 |  | 2   1 |  | 1 -2|
    |AB x AC| = (| 0 -3 |, | -3 -4 |, | -4 0|)

Формула за лице на успоредник и триъгълник в равнината (1 точка и 2 съседни)

         | x₁ y₁ 1 |               | x₁ y₁ 1 |
    S = || x₂ y₂ 1 ||   S = 1/2 * || x₂ y₂ 1 ||
         | x₃ y₃ 1 |               | x₃ y₃ 1 |

Формула за лице на успоредник и триъгълник в пространството (2 вектора с общо начало)

                     | x₂ x₃ |  | x₃ x₁ |  | x₁ x₂|
    S = |AB x AC| = (| y₂ y₃ |, | y₃ y₁ |, | y₁ y₂|)

                           | x₂ x₃ |  | x₃ x₁ |  | x₁ x₂|
    S = 1/2 * |AB x AC| = (| y₂ y₃ |, | y₃ y₁ |, | y₁ y₂|)

Формула за обем на паралелепипед и тетраедър в пространството (3 вектора с общо начало)

                     | x₁ y₁ z₁ |                          | x₁ y₁ z₁ |
    V = |(ABACAD)| = | x₂ y₂ z₂ |   V = 1/6 * |(ABACAD)| = | x₂ y₂ z₂ |
                     | x₃ y₃ z₃ |                          | x₃ y₃ z₃ |

---------- Права в равнината

Координатно параметрично уравнение на права в двумерното пространство намираме чрез точка и вектор съдържащ точката.

    g: { M(1, -2)  => {x = 1 - 1p , p ∈ ℝ
       { NM(-1 1)     {y = -2 + 1p

Намираме общо уравнение на права чрез колинеарност на 3 точки

    M(x, y)       | x  y 1 |
    A(1, -2)  <=> | 1 -2 1 | = 0
    B(0, -1)      | 0 -1 1 |

Намираме общо уравнение на права, на която лежи т. A(1, -2) и е успоредна на права a : 3x + 4y + 2 = 0

    Заместваме свободния член в успоредната права с променлива => 3x + 4y + c = 0
    Тъй като т. A лежи на a, то заместваме координатите на A в уравнението => 3 * 1 + 4 * (-2) + c = 0 => c = 5
    Тогава общото уравнение на търсената права е 3x + 4y + 5 = 0

Намираме общо уравнение на права, на която лежи т. A(1, -2) и е перпендикулярна на права a : 3x + 4y + 2 = 0

    Нормалният вектор на правата a е nₐ(3, 4) => координатното параметрично уравнение на търсената права е {x = 1 + 3λ
                                                                                                           {y = -2 + 4λ
    След елементарни преобразувания елиминираме λ и получаваме общото уравнение на правата: 4x - 3y - 10 = 0

    ИЛИ

    Разменяме коефициентите пред x и y в уравнението на a и сменяме знака на вторият коефициент => 4x - 3y + c = 0
    Заместваме координатите на A в новополученото уравнение => 4 * 1 - 3 * (-2) + c = 0 => c = -10
    Тогава общото уравнение на търсената права е 4x - 3y - 10 = 0

---------- Права и равнина в пространството

Координатно параметрично уравнение на права в тримерното пространство намираме чрез точка и вектор съдържащ точката.

                        {x = 1 + 4p
    g: { M(1, 2, 3)  => {y = 2 + 5p , p ∈ ℝ
       { NM(4, 5, -6)   {z = 3 - 6p

От едно координатно параметрично уравнение на права в тримерното пространство можем да вземем координати на всяка точка от нея

       {x = 1 + 4p
    g: {y = 2 + 5p  => всяка точка от правата има координати (1 + 4p, 2 + 5p, 3 - 6p)
       {z = 3 - 6p

От едно координатно параметрично уравнение на права в тримерното пространство можем да вземем точка (първия стълб
от числа) и вектор (втория стълб от числа), който е направляващ на правата (успореден на правата)

       {x = 1 + 4p
    g: {y = 2 + 5p  => G(1, 2, 3) и gᵥ(4, 5, -6)
       {z = 3 - 6p

От общо уравнение на равнина можем да вземем нормален вектор на правата. Всеки вектор, с координати кратни на координатите
на някой нормален вектор на правата е също нормален вектор на правата.

    α : 2x + 3y - 4z - 5 = 0 => nα(2, 3, -4)

Намираме общо уравнение на равнина чрез компланарност на 3 вектора
    MS(x - 3, y - 1, z - 4)     | x-3 y-1 z-4 |
    MN(-1, 0, -1)           <=> |  -1  0   -1 | = 0
    MP(-2, 1, -5)               |  -2  1   -5 |

При преминаване от уравнение на права, зададена чрез сечение на две равнини, към координанто параметрично уравнение:
    1. Избираме едната от променливите да е 0 и заместваме в уравнението => получаваме координати на точка
    2. Избираме друга от променливите да е 0 и заместваме в уравнението => получаваме координати на друга точка
    3. Ако видим че се получават дробни координати в някое заместване, имаме право да изберем някоя променлива да не е 0,
    а да бъде 1, 2, ... докато не намерим подходящи две точки само с координати естествени числа, а не дробни.

Векторите CH(1, 2, 3) и AB(1, 1, -1) са ортогонални, ако:
    (CH . AB) = 0 => 1 * 1 + 2 * 1 + 3 * (-1) = 0
