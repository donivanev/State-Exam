Колинеарност (линейна зависимост, лежат на една права) - a ∥ b
Компланарност (линейна зависимост, лежат на една равнина) - a ∥ π

----- Вектори -----

Събиране:
    • правило на ▲ - OB = OA + AB
    • правило на ▰ - PQ + PR = PS
Свойства:
    • a + b = b + a
    • (a + b) + c = a + (b + c)
    • a + 0 = a
    • a + (-a) = 0
Умножение с число:
    • ak = b
Свойства:
    • (m + n)a = ma + na
    • m(a + b) = ma + mb
    • m(na) = (mn)a
    • 1.a = a

-- Скаларно произведение

Дефиниция: <a, b> = (a . b) = |a|.|b|.cos∢(a, b)
Свойства: 
    • (a . b) = (b . a)
    • (a + b) . c = (a . c) + (b . c)
    • (a . b) = 0 ⟷ a ⟂ b
    • (a . a) = a² = |a|² => |a| = √a²

Координатно представяне:
    • a = (a₁, a₂, a₃) и b = (b₁, b₂, b₃) => a . b = a₁b₁ + a₂b₂ + a₃b₃

-- Векторно произведение

Дефиниция: a x b = |a|.|b|.sin∢(a, b)
Свойства: 
    • a x b = - b x a
    • (αa + βb) = α(a x c) + β(b x c)
    • a x b = 0 ⟷ a ∥ b
    • |a x b| = S успоредник
    • (a x b)² = a² . b² - (a . b)²

Координатно представяне:
    • a = (a₁, a₂, a₃) и b = (b₁, b₂, b₃) => a x b = (a₂b₃ - a₃b₂, a₃b₁ - a₁b₃, a₁b₂ - a₂b₁)

Двойно векторно произведение:
    • (a x b) x c = (a . c) . b - (b . c) . a
    • a x (b x c) = (a . c) . b - (a . b) . c

-- Смесено произведение

Дефиниция: (abc) = (a x b) . c
Свойства:
    • (abc) = (bca) = (cab)
    • ((λa₁ + μa₂) + bc) = λ(a₁bc) + μ(a₂bc)
    • (abc) = 0 ⟷ a, b, c са линейно зависими (компланарни)
    • ако a, b, c са линейно независими, то V паралелепипед = |(abc)| и V тетраедър = 1/6|(abc)|

Координатно представяне:
    • a = (a₁, a₂, a₃), b = (b₁, b₂, b₃), c = (c₁, c₂, c₃) =>
       |a₁, a₂, a₃|
    det|b₁, b₂, b₃| = a . (b x c) = a₁(b₂c₃ - b₃c₂) - a₂(b₁c₃ - b₃c₁) - a₃(b₁c₂ - b₂c₁)
       |c₁, c₂, c₃|
