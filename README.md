## State Exam - FMI

This repository is a structured collection of notes, theoretical materials, and practical problems for the **State Exam in Computer Science** at **FMI (Faculty of Mathematics and Informatics), Sofia University St. Kliment Ohridski**.

---

## 📁 Structure

### 📂 Theory
Contains LaTeX source files and compiled PDFs with theoretical summaries:
- **CS_FUND** – Fundamental computer science topics
- **CS_CORE1 / CORE2 / CORE3** – Core theoretical areas
- **MATH** – Mathematics topics relevant to the exam

---

### 📂 Problems
A collection of categorized problems with code examples and exam-style tasks.

#### 🔹 Procedural Programming
- C++ examples on pointers, memory management, arrays, recursion, bitwise operations

#### 🔹 Object-Oriented Programming
- C++ object-oriented design and examples

#### 🔹 Data Structures and Algorithms
- C++ implementations of core data structures

#### 🔹 Functional Programming
- Haskell exercises and lecture-style examples on lazy evaluation, recursion, pattern matching, type classes

#### 🔹 Databases
- SQL exercises and solutions covering both DDL and DML operations

#### 🔹 Artificial Intelligence
- Uninformed and informed state space search algorithms

#### 🔹 Mathematics
- Math notes and problems related to geometry, calculus and probability theory

#### 🔹 Logic Programming
- Prolog-based notes

#### 🔹 Systems Programming
- C and shell scripts for OS-related tasks covering file descriptors, process creation, signals, pipes

---

## 📌 Purpose

This repository is designed to:
- Help students prepare for the State Exam at FMI
- Provide categorized and practical examples in multiple programming paradigms
- Serve as a reference for algorithms, data structures, and theoretical foundations
